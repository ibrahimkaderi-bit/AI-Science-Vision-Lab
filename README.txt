AI Science Vision Lab — Mobile
=================================

مشروع علوم للصف العاشر يعمل بكاميرا الهاتف والرؤية الحاسوبية.

المزايا:
- اكتشاف وضعية الجسم مباشرة بواسطة MediaPipe Pose Landmarker.
- رسم الهيكل العظمي فوق فيديو الكاميرا.
- حساب زوايا الركبة والورك والمرفق.
- عدّ القرفصاء وثني الذراع.
- تجربة قفز مع تقدير بصري تعليمي لارتفاع القفزة.
- تسجيل القياسات وتصديرها CSV.
- إنشاء استنتاج علمي من الجلسة.
- PWA قابلة للإضافة للشاشة الرئيسية.

تشغيل الكاميرا:
المتصفحات الحديثة تسمح بالكاميرا فقط في Secure Context، لذلك افتح التطبيق من HTTPS
(مثل GitHub Pages / Netlify / Vercel) أو من localhost أثناء التطوير.

أول تشغيل:
يحتاج اتصال إنترنت لتحميل MediaPipe وملف النموذج. بعد تحميل الأصول قد يحتفظ بها
المتصفح/Service Worker للاستخدام اللاحق، حسب سياسات المتصفح والتخزين.

مهم:
التطبيق تعليمي وليس أداة طبية أو أداة قياس رياضي احترافية. قياس القفزة تقديري ويتأثر
بالمسافة والمنظور وزاوية الكاميرا.

ملف البداية: index.html
